## 功能介绍

照片地图是一个能够根据照片的地理位置信息（经纬度）在地图上展示照片的工具。通过这个工具，您可以：

- 在地图上直观地查看照片拍摄位置
- 根据拍摄地点浏览照片集
- 查看照片的详细信息，包括拍摄日期
- 以缩略图方式浏览同一地点的多张照片
- 以全屏方式查看原始照片
- **自动过滤：自动跳过没有GPS坐标信息的照片，只显示有地理位置信息的照片**

## 使用说明

### 地图导航

- 放大/缩小：使用鼠标滚轮或地图右上角的 +/- 按钮
- 移动地图：点击并拖动地图
- 切换地图类型：点击右上角的图层控制按钮，选择"电子地图"或"卫星影像"

### 照片查看

- 查看照片位置：地图上的缩略图标记表示照片拍摄位置
- 查看照片群组：数字标记表示该位置有多张照片，点击可查看
- 浏览照片列表：点击照片群组时，会显示该位置的所有照片缩略图
- 查看原图：点击任意缩略图可全屏查看原始照片
- 翻页浏览：使用全屏模式下的左右箭头或缩略图列表底部的分页按钮

## 技术特点

- **智能过滤**：自动识别并跳过没有GPS坐标的照片，确保地图只显示有地理位置信息的照片
- 自动聚合：相近位置的照片会自动聚合为照片群组
- 日期排序：照片按拍摄日期排序，方便时间线浏览
- 响应式布局：适配不同尺寸的屏幕
- 优化的缩略图：保持照片原始比例，提供更好的预览体验
- 美观的界面：渐变色、圆角、阴影等视觉元素提升用户体验
- **HEIC支持**：完整支持HEIC格式照片，自动转换为JPG并保留GPS信息

## 支持的文件格式

- JPEG/JPG
- PNG
- HEIC
